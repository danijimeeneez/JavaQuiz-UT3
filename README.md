# JavaQuiz - Práctica Integradora UT3

Aplicación de consola desarrollada en Java para la asignatura **Entornos de Desarrollo (1.º DAW - Curso 2026/2027)**[cite: 1]. 

## Finalidad del proyecto
El objetivo de este proyecto es poner en práctica el **control de versiones integrado en Visual Studio Code** y el **trabajo colaborativo mediante Git y GitHub** utilizando un repositorio remoto compartido[cite: 1].

El programa consiste en un concurso de preguntas y respuestas sobre conceptos básicos de Java dividido en dos rondas (3 preguntas por integrante)[cite: 1, 2]. Al finalizar las 6 preguntas, muestra el recuento total de aciertos obtenidos[cite: 1, 2].

## Integrantes y reparto de tareas
* **Integrante A ([Nombre y usuario de GitHub]):** Creación del repositorio, estructura inicial, `.gitignore`, `README.md` inicial y preguntas 1 a 3 (Ronda 1)[cite: 3, 5].
* **Integrante B ([Nombre y usuario de GitHub]):** Clonado del repositorio, preguntas 4 a 6 (Ronda 2), cálculo y muestra del resultado final y documentación de ejecución en el `README.md`[cite: 3].

## Requisitos técnicos
* **Java JDK** instalado en el equipo.
* **Visual Studio Code** con el paquete de extensiones de Java (*Extension Pack for Java*).
* Proyecto configurado sin herramientas de construcción externas (*No Build Tools*)[cite: 1, 2].
